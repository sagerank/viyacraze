# VIYACRAZE — Architectural Heavyweight Apparel

An editorial luxury streetwear digital experience featuring a 240-frame hardware-accelerated scroll-scrubbing engine, metallic gold vector branding, liquid glassmorphism, and a dedicated 3-page brand architecture.

---

## ✨ Features

- **60/120 FPS Frame Scrubbing Engine:** Pre-decoded GPU cache (`img.decode()`), direct physical-pixel mapping (`dpr`), and dirty-flag rendering across 240 high-detail WebP frames + hero sleeve photograph.
- **Fluid Lower-Third Cinematic HUD:** Non-obstructive narrative overlays synced with scroll progress, featuring pulsating live indicators and glassmorphic micro-badges.
- **3-Page Architecture:**
  - **Home (`index.html`):** Scroll canvas hero, Drop 01 capsule showcase, 280 GSM fabric anatomy, and editorial lookbook mosaic.
  - **Who We Are (`about.html`):** VIYACRAZE Manifesto, anti-fast-fashion origin story, The Four Pillars of Luxury Engineering, and atelier crafting timeline.
  - **Contact Us (`contact.html`):** Direct concierge channels (VIP WhatsApp, Email, Studio), interactive inquiry form, and interactive FAQ accordion.
- **Luxury Haute Couture Styling:** Obsidian noir palette (`#050507`), custom metallic gold vectors (`VIYA_logo_gold.svg`), `Cinzel` & `Syncopate` typography, and ambient cursor light mesh.
- **Store Ready:** Streamlined direct conversion pathways connecting seamlessly to the official storefront.

---

## 🚀 Getting Started

To run locally:

```bash
# Using Python 3
python3 -m http.server 8080

# Or using Node.js / npx serve
npx serve .
```

Open [http://localhost:8080](http://localhost:8080) in your browser.
